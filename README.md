# 🌊 Finpolar Backend
AI-powered stock analysis engine built with **LangGraph** and **FastAPI**.

### 🚀 Features
- **Autonomous Agents:** Multi-agent system using LangGraph.
- **Real-time Data:** Integrated with `yfinance` and `Polars`.
- **Streaming API:** Real-time token streaming via SSE.

### 🛠 Setup
1. `pip install -r requirements.txt`
2. `uvicorn project.api.app:app --reload`
